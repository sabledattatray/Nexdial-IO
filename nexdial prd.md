============================================================

Build a premium, modern, extremely fast, mobile-first B2B services website for NexDial.io.

- Advanced Excel work

- Data management
- Data cleaning
- Dashboard development
- Excel automation
- Power Query
- VBA/Macros
- Power BI
- Reporting automation
- Business data workflows

Secondary conversions:

- Request a quote
- View case study
- Download a sample/template
- Contact via email/WhatsApp if configured
- Visit Datta Sable authority profile

Brand relationship:
NexDial = commercial/client-facing service brand.
Dattasable.com = personal expertise, authority, educational content and professional identity.

Do not duplicate the two websites. NexDial should focus on business solutions and client acquisition.

21. PERFORMANCE REQUIREMENTS
============================================================

Performance is a first-class requirement.

Target:
- Excellent Core Web Vitals
- Fast first render
- Minimal JavaScript
- Minimal third-party scripts
- Optimized images
- Lazy-load below-the-fold images
- Use modern image formats where supported
- Avoid huge bundles
- Code split where appropriate
- Preload only truly critical resources
- Avoid render-blocking resources
- Avoid unnecessary animations
- Avoid heavy libraries when CSS/native browser features are sufficient

Targets:
LCP <= 2.5 seconds
INP <= 200 ms
CLS <= 0.1

Aim for strong Lighthouse scores, especially Performance, SEO, Accessibility and Best Practices.

Do not sacrifice accessibility or SEO merely to maximize a score.
